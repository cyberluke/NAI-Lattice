# nai-lattice-provider-opfs

AAF provider for Open Packaging Conventions (OPFS) package content.

Part of the [NAI Lattice](https://github.com/cyberluke/NAI-Lattice) workspace.

## Install

```toml
[dependencies]
nai-lattice-provider-opfs = "0.1"
```

## Status

**Scaffold.** The package name and role are reserved; the public API is not implemented yet. Do not depend on it for production.

Reserved AAF provider for Open Packaging Conventions content.
