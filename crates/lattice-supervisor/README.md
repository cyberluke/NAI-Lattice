# nai-lattice-supervisor

Process supervision and lifecycle management for NAI Lattice services.

Part of the [NAI Lattice](https://github.com/cyberluke/NAI-Lattice) workspace.

**First production integration:** [NAI OS](https://github.com/cyberluke/NAI-OS)
ships the NAI Lattice fabric host as its shared per-user runtime.

## Install

```toml
[dependencies]
nai-lattice-supervisor = "0.1"
```

## Status

Active.

## Role

Process supervision and lifecycle limits for host children.

## Workspace dependencies

None - this is a foundation crate.
