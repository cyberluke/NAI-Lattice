# nai-lattice-hotstore

HotStore trait: immutable-by-construction key/value abstraction over production hot stores.

Part of the [NAI Lattice](https://github.com/cyberluke/NAI-Lattice) workspace.

## Install

```toml
[dependencies]
nai-lattice-hotstore = "0.1"
```

## Status

Active.

## Role

Hot key/value store abstraction used by the runtime.

## Workspace dependencies

None - this is a foundation crate.
