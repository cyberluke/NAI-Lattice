# nai-lattice-embeddings

AAF-federated embeddings and rerank provider backed by the LUSI NPU gateway.

Part of [NAI Lattice](https://github.com/cyberluke/NAI-Lattice): a local-first,
event-sourced, multi-dimensional data fabric for Windows. This crate is one
building block of the workspace.

## Install

```toml
[dependencies]
nai-lattice-embeddings = "0.1"
```

## Status

Active.

## Role

Federated embeddings and rerank provider (LUSI NPU gateway).

## Workspace dependencies

- `nai-lattice-core`
- `nai-lattice-vector`
