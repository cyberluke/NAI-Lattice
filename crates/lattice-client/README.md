# nai-lattice-client

NAF/1 IPC client: connect to the per-user runtime, handshake, dispatch requests.

Part of the [NAI Lattice](https://github.com/cyberluke/NAI-Lattice) workspace.

## Install

```toml
[dependencies]
nai-lattice-client = "0.1"
```

## Status

Active.

## Role

Client-side NAF/1 connection, handshake and request dispatch.

## Workspace dependencies

- `nai-lattice-core`
- `nai-lattice-protocol`
