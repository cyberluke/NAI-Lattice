# nai-lattice-provider-filesystem

AAF provider for filesystem content discovery and reuse.

Part of the [NAI Lattice](https://github.com/cyberluke/NAI-Lattice) workspace.

**First production integration:** [NAI OS](https://github.com/cyberluke/NAI-OS)
ships the NAI Lattice fabric host as its shared per-user runtime.

## Install

```toml
[dependencies]
nai-lattice-provider-filesystem = "0.1"
```

## Status

**Scaffold.** The package name and role are reserved; the public API is not implemented yet. Do not depend on it for production.

## Role

Reserved AAF provider for filesystem content.
